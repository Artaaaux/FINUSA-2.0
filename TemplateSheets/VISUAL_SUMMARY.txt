🚀 5-MINUTE QUICK START
═══════════════════════════════════════════════════════════════════════════════

Step 1: Create Spreadsheet (1 min)
   ► Buka sheets.google.com
   ► Klik "Spreadsheet kosong"
   ► Buat 5 sheet dengan nama yang benar

Step 2: Setup Kategori (1 min)
   ► Sheet Kategori: Input 7 kategori default
   ► Makanan, Transport, Hiburan, Edukasi, Kesehatan, Utilitas, Lainnya

Step 3: Setup Input Harian (2 min)
   ► Header: Tanggal, Hari, Deskripsi, Kategori, Jumlah, Catatan
   ► Setup dropdown validasi di kolom Kategori
   ► Buat 100 baris kosong

Step 4: Setup Dashboard (1 min)
   ► Metrics card: Pemasukan, Pengeluaran, Sisa, Target
   ► Breakdown: Pengeluaran per kategori
   ► Insert Pie Chart

🔥 TOP 5 TIPS
═════════════════════════════════════════════════════════════════════════════

1️⃣  INPUT KONSISTEN
    ✓ Input setiap hari atau setelah pengeluaran
    ✓ Jangan skip pengeluaran sekecil apapun
    ✓ Gunakan deskripsi yang jelas

2️⃣  REVIEW MINGGUAN
    ✓ Setiap Jumat lihat sheet Analisis
    ✓ Identifikasi kategori yang paling boros
    ✓ Buat rencana penghematan minggu depan

3️⃣  LEVERAGE GRAFIK
    ✓ Pie chart lebih mudah dipahami dari tabel
    ✓ Progress bar motivasi Anda
    ✓ Visual data lebih powerful

4️⃣  CATEGORIZE DENGAN BENAR
    ✓ Kategori yang tepat = insight yang akurat
    ✓ Jangan overuse "Lainnya"
    ✓ Minimal ada 5 kategori substantive

5️⃣  SET TARGET REALISTIS
    ✓ Gunakan formula 50-30-20 sebagai baseline
    ✓ Minimal tabung 10% dari pemasukan
    ✓ Adjust sesuai kondisi real

🆘 TROUBLESHOOTING CEPAT
═════════════════════════════════════════════════════════════════════════════

❓ Dropdown kategori tidak muncul?
   → Setup data validation di sheet Input Harian kolom D
   → Range: Kategori!B2:B8

❓ Formula error #REF!?
   → Check sheet name benar (jangan typo)
   → Check range reference correct

❓ Dashboard jumlah 0?
   → Check semua pengeluaran sudah di-input
   → Check format kolom E adalah currency

❓ Grafik blank?
   → Check ada minimal 2 kategori dengan data
   → Buat ulang chart dengan data correct
