## 🚀 QUICK START (5 MENIT)

### Langkah 1: Buat Spreadsheet
```
1. Buka sheets.google.com
2. Klik "Spreadsheet kosong"
3. Nama: "FINUSA - Pengelolaan Keuangan Saya"
4. Buat 5 sheet: Dashboard, Input Harian, Kategori, Analisis, Target Tabung
```

### Langkah 2: Setup Kategori
Copy ke sheet "Kategori":
```
No | Kategori | Deskripsi
1 | Makanan & Minuman | Makanan, kopi, restoran
2 | Transport | Bensin, ojek, angkot
3 | Hiburan | Bioskop, game, liburan
4 | Edukasi | Buku, kursus, les
5 | Kesehatan | Obat, dokter, gym
6 | Utilitas | Listrik, air, internet
7 | Lainnya | Pengeluaran lain
```

### Langkah 3: Setup Input Harian
```
Header: Tanggal | Hari | Deskripsi | Kategori | Jumlah | Catatan
- Setup dropdown kategori di kolom D
- Format kolom E sebagai currency (Rp)
- Buat 100 baris kosong
```

### Langkah 4: Setup Dashboard
```
1. Buat metrics: Pemasukan, Pengeluaran, Sisa, Target
2. Buat breakdown pengeluaran per kategori
3. Insert pie chart untuk visualisasi
4. Insert table 10 pengeluaran terakhir
```

### Langkah 5: Test
```
Input 3-5 transaksi dummy → Lihat Dashboard terupdate? ✓
```

## 📊 STRUKTUR TEMPLATE

### Sheet 1: DASHBOARD
- **Ringkasan:** Pemasukan, Pengeluaran, Sisa, Target Tabung
- **Visual:** Pengeluaran per kategori dengan % dan progress bar
- **Grafik:** Pie chart & Bar chart
- **Data:** 10 transaksi terbaru

- **Kolom:** Tanggal, Hari, Deskripsi, Kategori, Jumlah, Catatan
- **Validasi:** Dropdown kategori
- **Format:** Currency & Date otomatis

- **Auto-sync:** Ke Dashboard & Analisis

### Sheet 3: KATEGORI
- **Default:** 7 kategori standar
- **Customizable:** Bisa tambah kategori baru
- **Referensi:** Dropdown di sheet Input Harian

### Sheet 4: ANALISIS

### Sheet 5: TARGET TABUNG

- **Progress:** Visual progress bar

## 📖 QUICK REFERENCE

### Saat Input Data
```
Tanggal: DD/MM/YYYY (contoh: 12/09/2024)
Hari: Auto-fill dengan formula
Deskripsi: Jelas & singkat (contoh: "Lunch di kantin", bukan "makan")
Kategori: Pilih dari dropdown (jangan create baru)
Jumlah: Angka saja, format otomatis jadi Rp
Catatan: Opsional (bisa skip)
```

```
Metrics: Pemasukan, Pengeluaran, Sisa, Target %
Breakdown: Kategori mana paling boros?
Grafik: Lihat pie chart untuk visual yang clear
Terbaru: 10 transaksi terakhir
```

```
1. Buka sheet Analisis

```

## 🛠️ COMMON SETUP ISSUES

### Issue: Dropdown kategori tidak muncul
**Fix:** 
1. Check sheet Kategori ada data
2. Setup data validation di sheet Input Harian kolom D
3. Range: Kategori!B2:B8

### Issue: Formula error #REF!
**Fix:**
1. Check sheet name benar (jangan typo)
2. Check range reference correct
3. Verify sheet sudah exist

### Issue: Jumlah di Dashboard 0 atau tidak ada
**Fix:**
1. Check semua pengeluaran sudah di-input
2. Check format kolom E adalah currency
3. Refresh browser atau tunggu beberapa detik

### Issue: Grafik blank atau error
**Fix:**
1. Check ada minimal 2 kategori dengan data
2. Check data range di chart editor correct
3. Buat ulang chart dengan data yang benar
