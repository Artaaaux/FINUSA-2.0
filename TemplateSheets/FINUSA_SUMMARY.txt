✅ Simple tapi powerful untuk semua level

📋 STRUKTUR TEMPLATE (5 SHEET)
═════════════════════════════════════════════════════════════════════════════

1. 📊 DASHBOARD
   ├─ Ringkasan: Total Pemasukan, Pengeluaran, Sisa, Target Tabung
   ├─ Breakdown: Pengeluaran per Kategori (Visual)
   ├─ Grafik: Pie Chart & Bar Chart
   └─ Terbaru: 10 Transaksi Terakhir

2. 📝 INPUT HARIAN
   ├─ Kolom: Tanggal, Hari, Deskripsi, Kategori, Jumlah, Catatan
   ├─ Validasi: Dropdown kategori, Format currency otomatis
   ├─ 100+ baris siap isi
   └─ Auto-sync ke Dashboard & Analisis

3. 📂 KATEGORI
   ├─ 7 Default: Makanan, Transport, Hiburan, Edukasi, Kesehatan, Utilitas, Lainnya
   ├─ Fleksibel: Bisa tambah kategori baru
   └─ Deskripsi: Jelas untuk guidance pengguna

4. 📈 ANALISIS
   ├─ Summary per kategori (Total, Rata-rata, Count, %)
   ├─ Tren 3 bulan terakhir
   ├─ Insight otomatis: Kategori tertinggi, Tren naik/turun
   └─ Grafik breakdown

5. 🎯 TARGET TABUNG
   ├─ 12 bulan tracking
   ├─ Progress bar visual
   ├─ Status indicator (Tercapai/Hampir/Belum)
   └─ History & proyeksi

✨ FITUR UNGGULAN
═════════════════════════════════════════════════════════════════════════════

1. OTOMASI PERHITUNGAN
   • SUM, SUMIF, AVERAGE, IF, QUERY formulas

4. CONDITIONAL FORMATTING

   • Color gradient untuk persentase

5. MOBILE-FRIENDLY
   • Akses di HP via Google Sheets app
   • Input mudah dengan keyboard
   • Auto-sync ke cloud

6. SCALABLE
   • Bisa track 100+ transaksi
   • Filter by kategori, tanggal, range
   • Export ke PDF/Excel untuk laporan

7. CUSTOMIZABLE
   • Add/edit kategori sesuai kebutuhan
   • Adjust target kapan saja
   • Rename sheet sesuai preferensi

🔧 FORMULA KUNCI
═════════════════════════════════════════════════════════════════════════════

DASHBOARD:
├─ Total Pemasukan: =SUMIF('Input Harian'!D:D,"Pemasukan",'Input Harian'!E:E)
├─ Total Pengeluaran: =SUM('Input Harian'!E:E)
├─ Sisa Uang: =B4-B5
├─ Target %: =IFERROR((B6/500000)*100,0)
├─ Per Kategori: =SUMIF('Input Harian'!D:D,"Makanan",'Input Harian'!E:E)
└─ Persentase: =IFERROR((B/SUM($B$:$B$))*100,0)

ANALISIS:
├─ Rata-rata: =AVERAGEIF('Input Harian'!D:D,A3,'Input Harian'!E:E)
├─ Count: =COUNTIF('Input Harian'!D:D,A3)
└─ Tren: =SUMIFS('Input Harian'!E:E,'Input Harian'!A:A,">="&DATE(2024,9,1))

🎓 BEST PRACTICES & TIPS
═════════════════════════════════════════════════════════════════════════════

DO:
✅ Input setiap hari (consistency is key)
✅ Review data mingguan (identify pattern)
✅ Categorize dengan benar (garbage in, garbage out)
✅ Backup bulanan (jangan hilang data)
✅ Adjust target sesuai kondisi (realistic)
✅ Share progress dengan support system (accountability)
✅ Celebrate achievement (motivation)

DON'T:
❌ Skip small expenses (Rp 10k juga dihitung!)
❌ Overuse "Lainnya" kategori (jadi tidak specific)
❌ Abaikan review data (pakai data buat keputusan)
❌ Set target terlalu ambitious (sustainable > aggressive)
❌ Share password (privacy)
❌ Manual calculation (pakai formula!)
❌ Mengubah formula sembarangan (bisa corrupt)

❓ FAQ

Q: Apakah template ini gratis?
A: Ya, 100% gratis! Hanya perlu akun Google (juga gratis).

Q: Bisakah saya menggunakan di HP?
A: Ya, download Google Sheets app, bisa input di HP juga.

Q: Bagaimana kalau saya tidak tech-savvy?
A: Template sangat simple, instruksi step-by-step tersedia. Bisa diikuti siapa saja.

Q: Apakah data saya aman?
A: Ya, tersimpan di Google Drive dengan enkripsi. Auto-backup.

Q: Bisa share dengan keluarga?
A: Ya, bisa. Share spreadsheet ke family members untuk kolaborasi budget.

Q: Berapa waktu untuk setup?
A: 5-10 menit untuk basic setup. 1-2 jam untuk full customization.

Q: Apa yang harus saya input setiap hari?
A: Cukup input pengeluaran (tanggal, deskripsi, kategori, jumlah). Yang lain otomatis.
